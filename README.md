# GEM under ChemVL Protocol

This repository is a fork of PaddleHelix for reproducing **GEM / GeoGNN** as an external baseline under the ChemVL MoleculeNet protocol.

The purpose of this fork is not to redesign GEM. It keeps the original PaddleHelix ChemRL/GEM model and adds a ChemVL-compatible evaluation wrapper so GEM can be compared fairly with MoleculeSTM, MoLFormer, ChemVL, and MolMCL-style baselines under the same datasets, split rules, seeds, metrics, and output format.

## Project Scope

| Model | Input | Finetune setup |
|---|---|---|
| GEM / GeoGNN | 2D graph plus 3D geometry features | Full-model fine-tuning with the official PaddleHelix GEM downstream head |

Benchmark tables:

| Table | Split | Datasets |
|---|---|---|
| A | `scaffold` | BACE, BBBP, ClinTox, HIV, SIDER, Tox21, ESOL, FreeSolv, Lipo, QM7 |
| B | `random_scaffold` | BACE, BBBP, ClinTox, HIV, SIDER, Tox21, ESOL, FreeSolv, Lipo, QM7 |

MoleculeACE Table C is not implemented in this fork. It would require a separate MoleculeACE loader and the MolMCL split protocol.

Metric convention follows ChemVL: classification uses ROC-AUC, QM7 uses MAE, and ESOL/FreeSolv/Lipo use RMSE. Each `(dataset, split)` setting is run with `runseed = 1, 2, 3`.

## Environment

Recommended environment:

```bash
conda create -n paddlehelix_chemvl python=3.8 pip
conda activate paddlehelix_chemvl
pip install numpy==1.24.4 pandas scikit-learn networkx tqdm
pip install rdkit-pypi==2022.9.5 pgl==2.2.6 paddlepaddle-gpu==2.6.2
```

RDKit affects Murcko scaffold generation. For strict split reproducibility, keep:

```text
rdkit-pypi==2022.9.5
```

## Data And Checkpoints

Set the ChemVL processed-data root:

```bash
export CHEMVL_DATA_ROOT=/path/to/chemvl-data
```

Expected MoleculeNet layout:

```text
${CHEMVL_DATA_ROOT}/finetuning_datasets/MPP/classification/<task>/processed/<task>_processed_ac.csv
${CHEMVL_DATA_ROOT}/finetuning_datasets/MPP/regression/<task>/processed/<task>_processed_ac.csv
```

Download official GEM checkpoints into the GEM directory:

```bash
cd apps/pretrained_compound/ChemRL/GEM
wget https://baidu-nlp.bj.bcebos.com/PaddleHelix/pretrained_models/compound/pretrain_models-chemrl_gem.tgz
tar xzf pretrain_models-chemrl_gem.tgz
```

Expected checkpoint files:

```text
apps/pretrained_compound/ChemRL/GEM/pretrain_models-chemrl_gem/class.pdparams
apps/pretrained_compound/ChemRL/GEM/pretrain_models-chemrl_gem/regr.pdparams
```

Checkpoints are runtime artifacts and should not be committed.

## Run Experiments

Move to the GEM application directory:

```bash
cd apps/pretrained_compound/ChemRL/GEM
```

Check split sizes without training:

```bash
SPLIT_ONLY=1 RUNSEED_START=1 RUNSEED_END=1 bash chemvl_protocol/run_moleculenet_scaffold.sh
SPLIT_ONLY=1 RUNSEED_START=1 RUNSEED_END=1 bash chemvl_protocol/run_moleculenet_random_scaffold.sh
```

Dry-run commands:

```bash
DRY_RUN=1 bash chemvl_protocol/run_moleculenet_scaffold.sh
DRY_RUN=1 bash chemvl_protocol/run_moleculenet_random_scaffold.sh
```

Run Table A/B:

```bash
bash chemvl_protocol/run_moleculenet_scaffold.sh
bash chemvl_protocol/run_moleculenet_random_scaffold.sh
```

Run both in the background:

```bash
bash chemvl_protocol/run_ab_background.sh
```

Useful override:

```bash
PYTHON=/path/to/python RUNSEED_START=1 RUNSEED_END=3 MAX_EPOCH=100 \
  bash chemvl_protocol/run_moleculenet_scaffold.sh
```

## Parameter Audit

Run one command from the repository root. A minimal verified audit environment is:

```bash
conda create -n gem_param_audit python=3.8 pip -y
conda activate gem_param_audit
pip install numpy==1.24.4 paddlepaddle==2.6.2 pgl==2.2.6 rdkit-pypi==2022.9.5
bash parameter_audit.sh --strict
```

The script writes:

```text
parameter_summary.csv
```

The audit first tries to instantiate `GeoGNNModel + DownstreamModel` and count `model.parameters()`. Use `--strict` when producing the formal table so dependency issues fail fast instead of falling back. If PaddlePaddle/PGL dependencies are not installed, the non-strict mode falls back to a transparent static architecture count from the checked-in `geognn_l8.json`, `down_mlp2.json`, and local PaddleHelix source. The fallback is marked as `STATIC_ARCHITECTURE_FALLBACK` in the CSV.

Default audit target is Table A `bbbp` with `num_tasks=1`, matching the formal comparison table. To audit a different head size:

```bash
bash parameter_audit.sh --dataset tox21 --num_tasks 12
bash parameter_audit.sh --output outputs/parameter_summary.csv
```

## Reproducibility Notes

- Split implementation uses RDKit Murcko scaffolds with chirality enabled by default.
- Classification labels are converted from ChemVL `0/1/-1 missing` to GEM `-1/1/0 missing` before training.
- Regression labels are standardized using the training split by default.
- GEM 3D/MMFF preprocessing is CPU-heavy; cached features are reused unless `--refresh-cache` is set.
- Loading official GEM checkpoints with PaddlePaddle 2.6.2 may print skipped-shape warnings for two atom embedding tensors; the completed runs used that setup.
